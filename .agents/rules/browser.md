# Снимки интерфейса: свой браузер, только headless

Проверять страницу снимком можно, не трогая браузер владельца. Правило
появилось после случая 2026-11-26: `pkill -x firefox` закрыл окна
пользователя вместе с временным экземпляром, который снимал страницу.

## Запуск

1. Профиль — отдельный, во временном каталоге (`/tmp/opencode/ffprof`),
   а не профиль пользователя.
2. Запуск с запоминанием PID: `MOZ_HEADLESS=1 firefox --headless
   --marionette --no-remote --profile /tmp/opencode/ffprof & ff_pid=$!`
3. Гасить только `kill $ff_pid`. `pkill firefox`, `pkill -x firefox` и
   `killall firefox` запрещены: они бьют по всем окнам, включая окна
   владельца.
4. Порт Marionette 2828 один на машину. Если он занят — временный
   экземпляр уже запущен: использовать его или погасить по сохранённому PID,
   а не по имени процесса.
5. Если временный экземпляр не отвечает, сначала `kill $ff_pid`, затем
   повторный запуск. Новый `--profile` без остановки старого даёт ошибку
   `profile is already in use`.

## Снимок

```
python3 .agents/tools/shot.py URL OUT.png [задержка]
```

Скрипт открывает страницу по протоколу Marionette, ждёт задержку (по
умолчанию 1,5 с) и пишет PNG. Задержка нужна страницам, которые получают
данные после монтирования: снимок сразу после `load` показывает начальное
состояние, а не результат запроса.

## Что известно про съёмку

- `firefox --screenshot` снимает на событии `load` и не видит ответов
  `fetch`: для страниц с данными годится только Marionette.
- Блокирующая задержка внутри страницы не помогает: ответ `fetch`
  разбирается тем же главным потоком, который занят задержкой, поэтому
  снимок всё равно обгоняет обновление стейта.
- Полная страница снимается `WebDriver:TakeScreenshot` с `full: true`;
  иначе в кадр попадает только видимая часть окна.
- Ответ на снимок приходит объектом `{"value": "<base64>"}`, а не строкой.

## Чего не делать

- Не открывать страницу в браузере пользователя и не менять его вкладки.
- Не оставлять временный браузер запущенным: после снимка `kill $ff_pid`.
- Не убивать процессы по имени (`pkill`, `killall`), если имя общее с
  пользовательскими программами. Исключение — процессы, запущенные самим
  агентом (например, `bin/tns`), и то по сохранённому PID.
