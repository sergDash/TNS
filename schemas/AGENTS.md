# Файлы схем

Здесь лежат машинно-проверяемые схемы: JSON Schema для настроек и обмена.

## Правила

- Имя файла — по предмету: `httpapi.schema.json`, `world.schema.json`.
- Форму описывает схема, значения — файл настроек рядом в `config/`.
- Схема и Go-структура не описывают одну и ту же форму независимо: структура
  объявляет известные поля, загрузчик проверяет обязательные и запрещает
  неизвестные ключи, схема описывает ту же форму для человека и инструментов.
- Пока нет валидатора JSON Schema, расхождение схемы и загрузчика ловится
  проверкой модуля при запуске, а не автоматически. Поэтому схема и загрузчик
  правятся в одной правке.
- Рядом со схемой лежит пример допустимых данных — сам файл настроек, на
  который она написана.

## Содержимое

| Файл | Предмет |
|---|---|
| `httpapi.schema.json` | настройки приложения `config/httpapi.json` |
| `world.schema.json` | перечни мира `config/world.json`, вместе с формой героя |
| `hero.schema.json` | форма героя: подключается из `world.schema.json` |
