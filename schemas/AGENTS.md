# Файлы схем

Здесь лежат машинно-проверяемые схемы: JSON Schema для настроек и обмена.
Схема — это канон: допустимые значения и форма данных. Файлы `config/`
хранят только выбранное из канона.

## Правила

- Имя файла — по предмету: `httpapi.schema.json`, `world.schema.json`.
- Канонические перечни (жанры, строи, сословия, рейтинги, языки) живут
  в схеме, в разделе `$defs`. Значения из них ограничиваются через `enum`.
- Конфиг рядом выбирает из канона: какие языки включены, чем заполнены поля
  героя. Загрузчик читает `$defs` схемы и проверяет, что каждый выбор есть
  в каноне; расхождение останавливает запуск с именем значения.
- Валидатора JSON Schema нет — ни в образце, ни здесь. Схему читает
  загрузчик модуля: ему нужны перечни и форма, а не проверка произвольных
  документов. Поэтому схема и загрузчик правятся в одной правке.
- Схема описывает форму для человека и инструментов; Go-структуры
  объявляют те же поля. Одно описание не должно отставать от другого.

## Содержимое

| Файл | Предмет |
|---|---|
| `httpapi.schema.json` | настройки приложения `config/httpapi.json` |
| `world.schema.json` | канон мира, форма героя и настройки `config/world.json` |
