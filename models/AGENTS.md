# Модели: файлы весов по ролям

Здесь лежат скачанные с Hugging Face веса — по папке на роль. Это данные
машины, а не исходники: каталог поставки (что можно скачать, с какими
суммами и размерами) лежит отдельно, в `config/models.json`.

## Структура

```
models/
  <роль>/
    <файл>.gguf     веса модели под исходным именем из ссылки
    <файл>.part     недокачанное: следующая попытка продолжит с места
    manifest.json   указатель версии: роль, источник, файл, sha256, размер, previous
```

Роли — `weaver` (модель прозы), `embed` (понимание реплик), `analysis`
(разбор главы). Список и варианты заданы в `config/models.json`; папка
роли, которой нет в каталоге, не читается.

Рядом, но не здесь: `bin/llama-server` и `bin/lib*.so` — сервер из архива
релиза, разложенный плоско. Сервер общий для всех ролей, поэтому у него
свой каталог.

## Правила

- **Установленной модель считается по сумме.** Файл на месте, но `manifest.json`
  с несовпавшим sha256 — модель не готова; при скачивании испорченный
  `.part` удаляется, чтобы не докачивать его снова.
- **Имена файлов — из ссылки.** Имя сравнивается с каталогом буквально;
  переименованный файл считается чужим.
- **Удаление — через экран моделей.** Оно снимает манифест и файлы роли
  вместе; ручное удаление оставит манифест, который указывает в пустоту.
- **Пути в настройках.** Каталог моделей задан в `config/httpapi.json` как
  `modules.settings.models.dir`; в коде умолчание то же — `models`.

Как устроен модуль (маршруты, работы, поток прогресса) — в
`domains/models/AGENTS.md`.

## Git

Содержимое папок ролей не попадает в репозиторий: это гигабайты данных.
В репозитории остаётся только это описание (`.gitignore`: `/models/*` кроме
`AGENTS.md`).
